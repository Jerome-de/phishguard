## Overview

An XGBoost-based phishing URL detection system trained on the
[UCI Phishing Websites Dataset](https://archive.ics.uci.edu/ml/datasets/phishing+websites)
(Mohammad, Thabtah & McCluskey, 2012).

This application extends the base paper by Chawla (2022) with:
- **SHAP-guided feature selection** — identifies the minimum sufficient feature subset
- **XGBoost** — not evaluated in any prior work on this dataset
- **GridSearchCV** hyperparameter optimisation
- **Live URL feature extraction** — users paste a raw URL, no manual feature entry required

**Model accuracy: 98.10%** (vs. 97.73% best in base paper)

## Setup: Adding the Trained Model

The URL Tester page requires two files that are generated by the training notebook:

| File | Description |
|------|-------------|
| `xgb_tuned_model.pkl` | The serialised tuned XGBoost model |
| `selected_features.pkl` | The SHAP-selected feature list |

**Steps:**
1. Run `phishing_url_detection.ipynb` in Google Colab (all sections top to bottom)
2. After Section 11 (serialisation), download both `.pkl` files from Colab:
   - Files panel → right-click each file → Download
3. Upload both files to this Hugging Face Space repository (drag & drop in the Files tab)
4. The Space will restart automatically and the URL Tester will become active

The **Model Analysis page** works without the model files.

## How URL Feature Extraction Works

When a URL is submitted, `feature_extractor.py`:

1. **Parses the URL** — scheme, domain, path, port, query parameters
2. **DNS lookup** — checks whether the domain resolves
3. **Fetches the page** (best-effort, 5s timeout) — extracts HTML-dependent features
4. **Computes all 30 UCI features** — each encoded as −1 (phishing), 0 (suspicious), or 1 (legitimate)
5. **Runs the XGBoost model** on the selected feature subset

Features that require live page content (form handlers, IFrame detection, anchor ratios)
fall back to URL-only heuristics when the page cannot be reached.
